# 📱 تطبيق رحلتي (Rihlaty) - تطبيق جوال متكامل

## 🎯 نظرة عامة

**رحلتي** هو تطبيق جوال متطور مبني باستخدام **Flutter** و **Supabase** يربط بين التجار وسائقي التكاتك لتسهيل عمليات نقل البضائع في مصر والسودان.

## 📦 محتويات الملف

```
rihlaty_app/
├── lib/                          # كود التطبيق الرئيسي
│   ├── config/                   # الإعدادات والثيم
│   ├── models/                   # نماذج البيانات
│   ├── providers/                # مزودو الحالة
│   ├── screens/                  # الشاشات (10+ شاشة)
│   ├── services/                 # الخدمات
│   └── main.dart                 # نقطة الدخول
├── android/                      # ملفات Android
├── ios/                          # ملفات iOS
├── pubspec.yaml                  # المكتبات والمتطلبات
├── DOCUMENTATION.md              # التوثيق الشاملة
├── SETUP.md                      # دليل البدء المفصل
├── QUICK_START.md                # دليل البدء السريع
├── ADMIN_ROLES_DOCUMENTATION.md  # توثيق الأدوار الإدارية
└── README.md                     # ملف التعريف
```

## 🎯 الخطوات التالية

### 1. الإعداد الأولي
```bash
cd rihlaty_app
flutter pub get
flutter run
```

### 2. إعداد Supabase (اختياري)
- أنشئ حساب على https://supabase.com
- أنشئ مشروع جديد
- احصل على المفاتيح
- حدّث `lib/config/constants.dart`

### 3. التطوير
- استكشف الشاشات المختلفة
- جرّب جميع الميزات
- اقرأ التوثيق الشاملة
- ابدأ بإضافة ميزات جديدة

## 🔧 الأوامر المفيدة

```bash
# تنظيف المشروع

# تحديث المكتبات

# بناء APK (Android)

flutter build ios --release
```

## 🐛 استكشاف الأخطاء

### خطأ: "flutter command not found"
```bash
export PATH="$PATH:[flutter-path]/bin"
```

### خطأ: "Gradle build failed"
```bash
flutter clean
flutter pub get
flutter run
```

### خطأ: "CocoaPods error" (iOS)
```bash
cd ios
rm Podfile.lock
cd ..
flutter pub get
flutter run
```
